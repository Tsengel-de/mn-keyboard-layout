🪟 Windows 7 / 10 / 11

Single Installer

Монгол кирилл болон бичгийн гарын байрлал, фонтуудыг нэг товшилтоор бүрэн суулгах бие даасан Windows суулгагч.

⚡ Windows Суулгагч Татах (.exe, 560 KB)
📁 .zip Эх сан (MSI & Source)
Суулгах: Татаж авсан Mongolian-Keyboard-Windows-Setup.exe дээр дарж суулгана. Суусны дараа Win + Space товчоор шууд монгол гар луу шилжинэ.

🍏 macOS (Apple Silicon & Intel)

Apple Native DMG

Apple-ийн албан ёсны стандартын Mongolian.bundle багц. DMG дискийг нээгээд шууд чирж (Drag & Drop) суулгана.

💿 macOS Диск Татах (.dmg, 1.3 MB)
📁 .zip Эх сан (1.2 MB)
Суулгах заавар (Энгийн 4 алхам):
  1. .dmg файл дээр 2 дарж нээнэ (Finder-т Mongolian Keyboard диск холбогдоно).
  2. Keyboard Layouts холбоос дээр 2 дарж нээгээд, Mongolian.bundle багцыг тийш чирж хуулна (нууц үг асуувал зөвшөөрнө).
  3. Fonts (System) холбоосыг 2 дарж нээгээд, Fonts хавтас доторх фонтуудыг тийш хуулна.
  4. Finder дээрх Mongolian Keyboard дискийг Eject (⏏️) хийж салгаад, System Settings → Keyboard → Input Sources-оос нэмнэ.

🐧 Linux (Ubuntu, Debian, Fedora, Arch)

XKB Unified

Бүх 3 хувилбарыг (Modern, Classic, Bichig) зэрэг суулгах, системд ээлтэй автомат суурилуулагч.
