🪟 Windows 7 / 10 / 11

Single Installer

Монгол кирилл болон бичгийн гарын байрлал, фонтуудыг нэг товшилтоор бүрэн суулгах бие даасан Windows суулгагч.

⚡ Windows Суулгагч Татах (.exe, 560 KB)
📁 .zip Эх сан (MSI & Source)
Суулгах: Татаж авсан Mongolian-Keyboard-Windows-Setup-v1.0.3.exe дээр дарж суулгана. Суусны дараа Win + Space товчоор шууд монгол гар луу шилжинэ.

🍏 macOS (Apple Silicon & Intel)

Apple Native DMG

Apple-ийн албан ёсны стандартын Mongolian.bundle багц. DMG дискийг нээгээд шууд чирж (Drag & Drop) суулгана.

💿 macOS Диск Татах (.dmg, 14 MB)
📁 .zip Эх сан (5.3 MB)
Суулгах заавар (Хялбар 2 сонголт):
  1. .dmg файл дээр 2 дарж нээнэ.
  2. Keyboard Installer.app-ийг нээж Mongolian.bundle-ийг цонх руу нь чирч суулгана (эсвэл ~/Library/Keyboard Layouts/ руу шууд хуулна).
  3. Системээс нэг удаа гарч (Log out) дахин орно (эсвэл restart).
  4. System Settings → Keyboard → Input Sources дээр + дарж Mongolian Cyrillic Ergonomic (Tsengel) нэмнэ.
